📝 Lab Exercises — Questions & Answers

❓
Question 1

What does the Creator field reveal about the true origin of this document?

Answer: Creator = Chrome user-agent string. Document was printed to PDF using Google Chrome, not Microsoft Word.

❓
Question 2

Which metadata source (Info dict or XMP) is more likely to be authentic, and why?

Answer: The XMP was injected after initial creation. The Info dict retains the original Chrome/Skia values. Info dict is more likely original; XMP was modified to fabricate a Word origin.

❓
Question 3

Is the ModDate value valid? What does it indicate?

Answer: No. ModDate (Feb 15) precedes CreationDate (Mar 1) — impossible in a normally produced file. Strong indicator of manual hex editing of metadata.

❓
Question 4

Write the peepdf3 command to display all metadata fields.

Answer: peepdf -i lab02_metadata.pdf then at prompt: pdf> metadata
