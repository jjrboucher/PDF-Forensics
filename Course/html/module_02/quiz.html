Document Metadata — Knowledge Check

📋
Knowledge Check
Answer all questions — 70% required to mark module complete
Question 1 of 5
A PDF's /Creator field contains a Chrome browser user-agent string. What does this tell you?

The /Creator field records the application that created the source document. A Chrome user-agent string means the PDF was produced using Chrome's built-in print-to-PDF function, commonly used to save web pages and emails as PDFs.

Question 2 of 5
You find that /ModDate is 15 February 2025 but /CreationDate is 1 March 2025. What is the correct conclusion?

A modification date that precedes the creation date is structurally impossible. A document cannot be modified before it is created. This is a reliable indicator that one or both date fields were manually edited.

Question 3 of 5
The Info dictionary shows Producer = 'Skia/PDF m124' but XMP shows pdf:Producer = 'Microsoft Word 2019'. Which source more likely reflects the true origin?

The Info dictionary typically retains the original values when only the XMP stream has been edited. In this scenario the Info dictionary showing Skia/PDF (Chrome's engine) is the original value — the XMP was edited to fabricate a Word origin.

Question 4 of 5
What is the xmpMM:DocumentID field and why is it forensically relevant?

The xmpMM:DocumentID is a UUID assigned once at document creation. Finding identical DocumentIDs in documents purportedly from different independent sources can indicate they share a common template or that one was copied from the other.

Question 5 of 5
What command in peepdf displays all metadata fields?

The 'metadata' command displays all metadata from the Info dictionary and, where available, the XMP stream. The 'info' command shows structural information (version, object count) rather than document metadata.
