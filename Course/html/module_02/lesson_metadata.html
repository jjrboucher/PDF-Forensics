Document Metadata: Two Sources, One Truth

Every PDF carries metadata in two parallel structures. When they disagree, someone edited one after the fact.

📋 1. Two Metadata Sources

Info Dictionary
Traditional key-value dictionary
Referenced from the file trailer
Easy to edit with any PDF tool
Present since PDF 1.0
XMP Metadata Stream
XML document in the Document Catalog
Uses standard namespaces (xmp:, pdf:, xmpMM:)
Introduced in PDF 1.4 (Acrobat 5.0)
Contains DocumentID and InstanceID
🚨
The Core Principle

A PDF produced normally will have identical values in both sources. A discrepancy means one source was edited after the other — the unedited source reflects the true original value.

🏷 2. Key Metadata Fields

FieldInfo KeyXMP FieldWhat to Look For
Creator/Creatorxmp:CreatorToolThe application that created the source document. Chrome user-agent = browser print-to-PDF.
Producer/Producerpdf:Producer"Skia/PDF m124" = Chrome. "Acrobat Distiller" = Adobe. Mismatch between sources = edited.
CreationDate/CreationDatexmp:CreateDateMust be ≤ ModDate. Timezone offset may reveal creator locale.
ModDate/ModDatexmp:ModifyDateMust be ≥ CreationDate. If earlier: certain manual editing.

📅 3. PDF Date Format

PDF dates use the format: D:YYYYMMDDHHmmSSOHH'mm'
Example: D:20250301120000+00'00' — 1 March 2025 12:00:00 UTC

🚨 4. The Three Anomaly Classes

ANOMALY-1Creator / Producer — Origin MismatchHIGH

The Creator or Producer field identifies a different application than the document's claimed origin.

Claimed
"Prepared in Microsoft Word"
Actual Info Dict
Creator: Mozilla/5.0...Chrome/124...
Producer: Skia/PDF m124
Significance
Document was printed to PDF using Google Chrome, not created in Word
ANOMALY-2Impossible Date — ModDate Before CreationDateHIGH

The modification date precedes the creation date — structurally impossible in a normally produced PDF.

CreationDate
D:20250301120000+00'00' (1 March 2025)
ModDate
D:20250215083000+00'00' (15 February 2025 — BEFORE creation)
Significance
One or both date fields have been manually edited
ANOMALY-3Info Dictionary / XMP DivergenceHIGH

The Info dictionary and XMP stream record different values for the same field.

Info Producer
Skia/PDF m124 (original)
XMP Producer
Microsoft Word 2019 (edited)
Info ModDate
D:20250215... (original)
XMP ModifyDate
2025-03-01T12:00:00Z (differs)
