Scenario

You have received a one-page financial document. The submitting party claims it was prepared in Microsoft Word 2019 and signed on 1 March 2025. Your task is to verify whether the metadata supports or contradicts this claim. There are three planted anomalies in this file; your job is to find and document all three.

ℹ️
Before You Begin

Open a terminal, navigate to the folder containing lab02_metadata.pdf, and prepare a notes document. You will be comparing values across two metadata sources (the Info dictionary and the XMP stream), so a two-column layout works well. Draw a table with columns: Field | Info Dictionary | XMP Stream | Match?

🔬 Exercise 1 — Verify the File Hash

Hash the file before examining it. This is your integrity baseline and must be recorded in any forensic case log.

🪟 Windows
🐧 Linux / macOS
PowerShell — hash the file
Get-FileHash -Algorithm MD5 lab02_metadata.pdf
# Expected: d2199d83e50edbdde67b4d5940b665b7

Get-FileHash -Algorithm SHA256 lab02_metadata.pdf
# Record both values in your notes.
Bash — hash the file
md5sum lab02_metadata.pdf
# Expected: d2199d83e50edbdde67b4d5940b665b7

sha256sum lab02_metadata.pdf
# Record both values.
✅
What to record

Write these down in your notes before moving on:

  • MD5 and SHA256 hashes confirmed matching
  • Date, time, and tool used (Get-FileHash / md5sum + sha256sum)

🔬 Exercise 2 — Extract the Info Dictionary

The Info dictionary is the first metadata source. Use two tools so you can see how each presents the same data — you will use both in later cases.

🪟 Windows
🐧 Linux / macOS
PowerShell — Info dictionary via peepdf and ExifTool
# Method 1: peepdf (shows raw PDF values)
peepdf -i lab02_metadata.pdf
pdf> metadata
# This shows the Info dictionary AND the XMP stream together.
# Look for and record:
#   /Creator     <- the application that created the source document
#   /Producer    <- the application that produced the PDF
#   /CreationDate
#   /ModDate
pdf> exit

# Method 2: ExifTool (human-readable labels)
exiftool lab02_metadata.pdf
# Look for: Creator, Producer, Create Date, Modify Date
# ExifTool reads the Info dict by default.
Bash — Info dictionary via peepdf and ExifTool
# Method 1: peepdf
peepdf -i lab02_metadata.pdf
pdf> metadata
# Record: /Creator, /Producer, /CreationDate, /ModDate
pdf> exit

# Method 2: ExifTool
exiftool lab02_metadata.pdf
# Look for: Creator, Producer, Create Date, Modify Date
✅
What to record

Write these down in your notes before moving on:

  • Info /Creator: write down the exact string
  • Info /Producer: write down the exact string
  • Info /CreationDate: write down the full date-time string including timezone
  • Info /ModDate: write down the full date-time string
  • Does the Creator string look like it came from Microsoft Word? Or something else?

🔬 Exercise 3 — Extract the XMP Stream

The XMP stream is the second metadata source. It should contain identical values to the Info dictionary if the document has not been tampered with. You will compare the two sources after this step.

🪟 Windows
🐧 Linux / macOS
PowerShell — XMP stream via peepdf
peepdf -i lab02_metadata.pdf

# Step 1: find the Metadata object number
pdf> search /Metadata
# The output shows which object number holds the XMP stream

# Step 2: read that object
pdf> object METADATA_OBJ_NUM
# This displays raw XML. Look for these tags:
#   xmp:CreatorTool     <- equivalent of Info /Creator
#   pdf:Producer        <- equivalent of Info /Producer
#   xmp:CreateDate      <- equivalent of Info /CreationDate
#   xmp:ModifyDate      <- equivalent of Info /ModDate
#   xmpMM:DocumentID    <- unique document UUID
pdf> exit
Bash — XMP stream via peepdf
peepdf -i lab02_metadata.pdf
pdf> search /Metadata
# Note the object number shown
pdf> object METADATA_OBJ_NUM
# In the XML output, look for:
#   xmp:CreatorTool, pdf:Producer
#   xmp:CreateDate, xmp:ModifyDate
#   xmpMM:DocumentID
pdf> exit

# Alternative: ExifTool shows XMP fields with 'XMP-' prefix
exiftool -XMP:all lab02_metadata.pdf
✅
What to record

Write these down in your notes before moving on:

  • XMP xmp:CreatorTool: write down the exact value
  • XMP pdf:Producer: write down the exact value
  • XMP xmp:CreateDate: write down the full value
  • XMP xmp:ModifyDate: write down the full value
  • xmpMM:DocumentID: record the UUID

How to spot the anomalies

ANOMALY-1 (Origin mismatch): Does the Creator string match what you would expect from Microsoft Word? A Creator string starting with Mozilla/5.0 is a browser user-agent — the document was printed to PDF in Chrome, not authored in Word.

ANOMALY-2 (Impossible date): Compare the CreationDate and ModDate. Can a document be modified before it was created? If ModDate is earlier than CreationDate, one of those values has been manually edited.

ANOMALY-3 (Info/XMP divergence): Do the values in both columns match? A mismatch means one source was edited after the other was written. The unedited source holds the original value.

📝 Knowledge Check Preparation

Use your notes to answer these questions before checking the answers below.

Q1: The /Creator field contains a Chrome user-agent string. What does this tell you about the document's origin?
The /Creator field records the application that created the source document. A Chrome user-agent string (e.g. Mozilla/5.0...Chrome/124...) means the PDF was produced by printing to PDF in Google Chrome — not authored in Microsoft Word as claimed. The /Producer: Skia/PDF m124 (Chrome's PDF engine) confirms this.
Q2: The ModDate is 15 February 2025 but the CreationDate is 1 March 2025. What is the correct conclusion?
A document cannot be modified before it is created. ModDate 15 Feb precedes CreationDate 1 Mar — this is structurally impossible in a legitimately produced PDF. One or both date fields were manually edited after creation. This is ANOMALY-2.
Q3: Which source (Info dict or XMP) more likely reflects the true Creator/Producer?
The Info dictionary. The Info dict shows Creator: Mozilla/5.0...Chrome/124... and Producer: Skia/PDF m124 — consistent with a Chrome-generated PDF. The XMP was edited to claim Microsoft Word origin. When sources diverge, the one consistent with other evidence (the Chrome Creator) is the more reliable original record.
Q5: What peepdf command displays all metadata fields from both the Info dictionary and XMP stream?
pdf> metadata — run after opening the file with peepdf -i lab02_metadata.pdf. It outputs both sources together, making it the fastest single command for metadata comparison.

Documentation Exercise

Write two sentences suitable for inclusion in a forensic report about ANOMALY-2 (the impossible date). Your statement must: (1) state both date values precisely; (2) explain why the sequence is impossible; (3) state the forensic conclusion. Write your answer before revealing the model below.

Model statement: “The Info dictionary records a ModDate of 15 February 2025 (D:20250215083000+00'00'), which precedes the document CreationDate of 1 March 2025 (D:20250301120000+00'00') by 14 days. As a document cannot be modified before it is created, this sequence is structurally impossible in a legitimately produced PDF file and is consistent with the deliberate manual editing of one or both date fields after the document was originally produced.”
