Capstone Lab: Service Agreement SA-2025-0847

A complete, unsupported forensic analysis. Apply every technique from Modules 01–06 to a single multi-artifact document. No step-by-step prompts — this is your independent examination.

Scenario

Document: Service Agreement SA-2025-0847 between Northgate Consulting Ltd and Vantage Solutions Inc.
Claimed value: $240,000 over 12 months
Claimed creation: Microsoft Word 2021, 15 October 2025, London
Your task: Conduct a complete forensic analysis. There are 5 distinct findings across 5 pages, covering multiple artifact categories.

🚨
Capstone Rules

Work through your own analysis fully before revealing any answers. This exercise tests your ability to conduct an independent examination. The answer key is available at the bottom — use it only to check your findings after you have completed your own work.

⚙️ Your Examination Workflow

Follow this sequence. Each step uses exactly the techniques from the corresponding module. Record everything — object numbers, commands run, exact values found.

1
Hash the file

Record MD5 and SHA256 before touching anything else. Note the date, time, and tool version.

Windows / Linux
Get-FileHash -Algorithm MD5 lab07_capstone.pdf
Get-FileHash -Algorithm SHA256 lab07_capstone.pdf
# Linux: md5sum lab07_capstone.pdf && sha256sum lab07_capstone.pdf
2
Metadata triage (Module 02 technique)

Check Creator and Producer in both the Info dictionary and XMP stream. Compare the two sources. Does the claimed Microsoft Word 2021 origin hold up?

peepdf / ExifTool
peepdf -i lab07_capstone.pdf
pdf> metadata
# Record: Info /Creator, Info /Producer, XMP xmp:CreatorTool, XMP pdf:Producer
# Do the Info dict and XMP agree?
pdf> exit

exiftool lab07_capstone.pdf
3
Incremental update check (Module 03 technique)

Count %%EOF markers. If more than one, extract prior versions and compare content.

Python
python -c "d=open('lab07_capstone.pdf','rb').read(); print(d.count(b'%%EOF'),'EOF markers')"
# If count > 1, get offsets and extract earlier versions as in Module 03
4
Text overlay scan — all pages (Module 05 technique)

For each page: check /Annots for FreeText overlays, decode the content stream and search for '1 1 1 rg re f' (white-box), and compare Td coordinates across BT...ET blocks (text-over-text). Note the covered and replacement values.

peepdf + qpdf — all pages
peepdf -i lab07_capstone.pdf
pdf> page 1
pdf> page 2
pdf> page 3
pdf> page 4
pdf> page 5
# Note /Annots entries and /Contents object numbers for each page
pdf> exit

# Decode each page content stream:
qpdf --show-object=CONTENTS_OBJ --filtered-stream-data lab07_capstone.pdf > pageN_stream.txt
# Search for: 1 1 1 rg  (white-box) and duplicate Td coordinates (text-over-text)
5
Image manipulation scan — all pages (Module 04 technique)

Check for BBOX_CROP (compare Form /BBox to cm matrix values), OVERLAP (two images on same page), and OFFPAGE (negative cm coordinates). Extract all images with mutool and note any with suspicious crop ratios.

peepdf + mutool
peepdf -i lab07_capstone.pdf
pdf> tree
# Look for Form XObjects (/Subtype /Form) on any page
# For each Form, read its /BBox and decode its content stream
pdf> exit

mutool extract lab07_capstone.pdf
# Open all extracted images and look for unexpected content
6
EXIF and GPS analysis (Module 06 technique)

Extract all images and run ExifTool. Check Make/Model against claimed capture device. Check GPS coordinates against claimed location (London). Note DateTimeOriginal against the contract date of 15 October 2025.

mutool + ExifTool
mutool extract lab07_capstone.pdf
exiftool img-*.jpg
# Key fields: Make, Model, DateTimeOriginal, GPSLatitude, GPSLongitude
exiftool -csv -GPSLatitude# -GPSLongitude# img-*.jpg
# Look up any GPS coordinates at maps.google.com
7
Counter-verify every finding with manual tools

For every finding: note the object number, run qpdf --show-object=N to display the raw data, and confirm your finding independently. Record the exact command and output for each.

qpdf
# For each finding from steps 2-6:
qpdf --show-object=FINDING_OBJ_NUM lab07_capstone.pdf
# This is the independent verification step that makes findings court-ready
