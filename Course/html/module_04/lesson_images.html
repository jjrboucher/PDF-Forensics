Image Manipulation: Four Hiding Techniques

✂️ 1. BBOX_CROP

A Form XObject's /BBox acts as a rectangular mask. When an image is placed inside at a larger size than the BBox, the excess is cropped and hidden — but the full pixel data remains in the file.

BBOX_CROPBBox Boundary CropHIGH

Image placement extends beyond the Form XObject's /BBox. Content outside the BBox is invisible but intact.

Risk Weight
+30
Detection
image_display_rect.any_edge > bbox.corresponding_edge + 1.0 pt
False Positive
Professional layout tools (InDesign, Illustrator) legitimately crop images for design purposes
BBOX_CROP — Annotated PDF Syntax
7 0 obj
<< /BBox [0 0 200 150]   ← only 200x150 pts rendered
   /Resources << /XObject << /ImA 8 0 R >> >> >>
stream
  400 0 0 300 0 0 cm  ← image placed at 400x300 pts (DOUBLE the BBox)
  /ImA Do
endstream

🔲 2. OVERLAP

Two images are placed with overlapping display regions. The image drawn first in the content stream is behind (hidden); the image drawn second is on top.

OVERLAPOverlapping Image PlacementHIGH

Two image bounding boxes intersect. Classified as FULL (back image completely inside front) or PARTIAL.

Risk Weight (FULL)
+35 (highest weight in scoring model)
Risk Weight (PARTIAL)
+15 / +8
False Positive
Full-page background images (watermarks, letterheads) produce FULL OVERLAP for every page image

📏 3. OFFPAGE

An image's display rectangle extends beyond the page's CropBox. Content outside the CropBox is not rendered by any compliant PDF viewer, but the image data remains fully intact in the file.

OFFPAGEOff-Page Image ContentHIGH

Image display rect extends beyond the page CropBox boundary. The off-page portion is invisible but intact.

Risk Weight
+25
Example
Image at x=-80 on a page with left edge x=0 → 80 pts (26.7%) off-page left

📐 4. DPI_ANOMALY

The effective DPI is computed from pixel dimensions and display size:

DPI Calculation
effective_dpi_x = (pixel_width  * 72) / display_width_pts
effective_dpi_y = (pixel_height * 72) / display_height_pts

# Example: 150px wide, displayed at 150 pts:
effective_dpi = (150 * 72) / 150 = 72 DPI  # screenshot resolution

# Example: 600px wide, displayed at 144 pts:
effective_dpi = (600 * 72) / 144 = 300 DPI  # scanner resolution
DPI RangeClassificationTypical Source
< 100ScreenshotScreen capture at display resolution, web image
100–199Low-resResized image, fax scan
200–349Standard scanOffice scanner — normal for document workflows
≥ 350High-resProfessional scanner, DSLR camera
