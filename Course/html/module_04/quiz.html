Image Manipulation — Knowledge Check

📋
Knowledge Check
Answer all questions — 70% required to mark module complete
Question 1 of 5
A Form XObject has /BBox [0 0 200 150]. An image inside it uses the matrix '400 0 0 300 0 0 cm'. What percentage of the image area is hidden?

Image is placed at 400x300 pts. BBox is 200x150 pts. Visible width = 200/400 = 50%. Visible height = 150/300 = 50%. Visible area = 50% x 50% = 25%. Hidden area = 75%.

Question 2 of 5
When two images overlap (OVERLAP finding), which image is considered the hidden 'back' image?

Content is rendered in the order it appears in the content stream. The image drawn first (earlier in the stream) is behind; the image drawn later is on top and conceals it.

Question 3 of 5
An image is placed at x=-80 pts on a page with MediaBox [0 0 612 792]. What does the OFFPAGE finding mean?

A MediaBox left edge of x=0 means anything at x<0 is off the visible page. An image at x=-80 has its leftmost 80 pts outside the visible area. Those pixels exist in the file but are never rendered.

Question 4 of 5
An image has 150 pixels of width and is displayed at 150 points wide. What is its effective DPI?

Effective DPI = pixel_width x 72 / display_width_pts = 150 x 72 / 150 = 72 DPI. This is screen resolution — consistent with a screenshot or web image, not a scanned document.

Question 5 of 5
Which command extracts the full uncropped image from a BBOX_CROP finding?

'mutool extract' extracts all embedded image resources to the current directory. This gives you the complete uncropped pixel data regardless of how the PDF renders it.
