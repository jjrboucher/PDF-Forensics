Module 01

PDF Internals

Understand the building blocks of a PDF file — the same structures that forensic artifacts exploit.

⏱ ~60 minutes📄 Lab file: lab01_structure.pdf📋 6-question quiz

🎯 Learning Objectives

  1. Describe the four structural sections of a PDF file
  2. Locate and read any indirect object using its object number and byte offset
  3. Decode a compressed content stream using qpdf or peepdf
  4. Explain the role of the cross-reference table and trailer in file parsing
  5. Distinguish between Image XObjects and Form XObjects and explain their forensic significance
