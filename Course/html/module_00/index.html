Module 00

Setup & Orientation

Install your toolset, verify your environment, and establish your baseline workflow before beginning PDF analysis.

⏱ 20 minutes🧪 1 Lab Exercise

🎯 Learning Objectives

  1. Install and verify all required tools on Windows and Linux
  2. Hash a PDF file and record the value correctly for case documentation
  3. Navigate to a PDF file from the command line and perform basic inspection
  4. Launch the PDF Forensics Application and load a case folder

ℹ️
Note on peepdf

This course uses peepdf, the Python 3 port of the original peepdf tool. The correct install command is pip install peepdf-3 (with a hyphen). Launch with: peepdf <file.pdf> or peepdf -i <file.pdf>.

⚠️
Windows Users — PATH Configuration Required

None of qpdf, mutool, or ExifTool are usable from a Windows terminal until their install locations are added to your system PATH environment variable. This is not optional — every command in this course assumes these tools resolve by name (qpdf, mutool, exiftool) from any folder. The full step-by-step PATH setup for each tool, including building mutool from source, is covered in Step 1 of the lab below. Complete that setup before attempting Step 3 (tool verification).

If you prefer not to configure PATH manually, Windows Subsystem for Linux (WSL) is an alternative: all tools install with a single sudo apt install command and PATH is configured automatically. This requires basic familiarity with the Linux command line.

🔬 Forensic Workflow Principle

  1. Hash first. Record SHA-256 and MD5 of every source file before analysis.
  2. Work on copies. Never analyse the original exhibit directly.
  3. Document every command. Record exact commands, tool version, and output.
  4. Record tool versions. Examiners must be able to reproduce findings.
