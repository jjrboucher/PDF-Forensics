EXIF & GPS: The Camera's Story

📷 1. What is EXIF?

EXIF (Exchangeable Image File Format, JEITA CP-3451C) is metadata embedded inside JPEG and TIFF image files. When an image is embedded in a PDF, its EXIF data travels with it intact.

EXIF TagField NameForensic Use
0x010FMakeCamera/scanner manufacturer — should be consistent across a scanned document
0x0110ModelSpecific device model — distinguishes scanner from smartphone from DSLR
0x0131SoftwareProcessing software — "Adobe Photoshop" on a raw scan is a red flag
0x9003DateTimeOriginalOriginal capture timestamp — more reliable than DateTime
0x8825GPSInfoSub-IFD containing latitude, longitude, altitude, GPS timestamp
⚠️
EXIF Caveats

EXIF data can be edited by image editing software. GPS coordinates do not guarantee the image was captured at that location. Always corroborate EXIF evidence with other sources. However, the absence of EXIF editing traces (consistent with the stated capture scenario) is itself a positive authenticity indicator.

🌍 2. GPS Coordinates

GPS Coordinate Conversion
# GPS stored as degrees/minutes/seconds:
GPSLatitude:  48 deg 51' 23.76" N
GPSLongitude:  2 deg 21'  7.92" E

# Convert to decimal degrees:
Lat_DD  = 48 + 51/60 + 23.76/3600 = 48.8566 N
Lon_DD  =  2 + 21/60 +  7.92/3600 =  2.3522 E

# This resolves to: Paris, France
# Verify: https://maps.google.com?q=48.8566,2.3522

📱 3. Mixed Camera Detection

In a legitimately scanned document, all pages are scanned by the same device. EXIF Make and Model should be uniform.

Make / ModelDevice TypeForensic Significance
Canon imageRUNNEROffice scannerExpected for a scanned document
SAMSUNG SM-G991BSamsung Galaxy smartphonePhotograph taken on a phone — not a scanner
Apple iPhone 15 ProiPhonePhotograph taken on a phone — not a scanner
FUJIFILM X-T5Mirrorless cameraPhotograph taken on a camera — not a scanner

💬 4. Reviewer Annotations

Reviewer annotations (sticky notes, highlights, FreeText comments) are stored in the /Annots array on each page. Key fields:

FieldPDF KeyNote
Author/TFree-text — the OS username of the annotating user. Not verified, can be faked.
Contents/ContentsThe comment text — often contains contextual information
Created/CreationDateWhen the annotation was created
