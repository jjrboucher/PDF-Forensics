EXIF & GPS — Knowledge Check

📋
Knowledge Check

Question 1 of 5
An image embedded in a PDF has EXIF Make = 'SAMSUNG' and Model = 'SM-G991B'. The document claims all images are scanned. What is the forensic significance?

The Samsung SM-G991B is a Galaxy S21 smartphone. EXIF Make/Model fields identify the capture device. A smartphone-originated image in a supposedly scanned document is a significant anomaly requiring explanation.

Question 2 of 5
You extract a JPEG from a PDF and ExifTool shows GPSLatitude: 25.2048, GPSLongitude: 55.2708. The document claims the photo was taken in London, UK. What should you do next?

25.2°N, 55.3°E is Dubai, UAE. You should look up the coordinates, document the discrepancy with the stated provenance, and seek corroborating evidence. Do not accept or reject the claim on GPS alone.

Question 3 of 5
Which ExifTool command extracts GPS coordinates in decimal degree format from all JPEGs in the current directory?

The # suffix forces numeric output in ExifTool. '-csv' formats as comma-separated values. This gives decimal-degree coordinates that can be pasted directly into mapping services.

Question 4 of 5
A reviewer annotation has /T (D. Chen) and /CreationDate (D:20251112093000). What does the /T field represent and how reliable is it?

The /T field is the annotation's title or author field. It is set to whatever name is configured in the PDF editor's preferences. It has no authentication mechanism and can be set to any value. Use it as a lead, not definitive proof.

Question 5 of 5
When using mutool to extract images from a PDF, where are the files saved?

'mutool extract' saves extracted resources to the current working directory. Navigate to your intended output directory before running the command.
