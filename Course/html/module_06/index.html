Module 06

EXIF, GPS & Document Comments

Images carry metadata about where and how they were captured. Annotations carry reviewer identity and timestamps. Both are often overlooked — and highly evidential.

⏱ ~55 minutes📄 Lab file: lab06_exif_comments.pdf

🎯 Learning Objectives

  1. Extract EXIF metadata from images embedded in a PDF using ExifTool and mutool
  2. Interpret GPS coordinates to determine the location where an image was captured
  3. Identify mixed-camera anomalies across a multi-page document
  4. Extract all reviewer annotations with author names and timestamps
