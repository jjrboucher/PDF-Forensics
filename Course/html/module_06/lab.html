Scenario

You have received a three-page site inspection report. The submitting party claims all photographs were captured at the company's London office using the office Canon scanner on 10–15 November 2025. Your task is to verify or refute this claim using EXIF metadata analysis.

ℹ️
Before You Begin

Open a terminal in the folder containing lab06_exif_comments.pdf. You will first extract images to separate files, then run ExifTool on each. Prepare a table in your notes with columns: Image filename | Page | Make | Model | DateTimeOriginal | GPS present? | GPS location | Anomaly?

🔬 Exercise 1 — Extract Images and Run ExifTool

Use mutool to extract all embedded images, then run ExifTool on all three to capture their EXIF metadata. Save the output to a file so you can review it carefully.

🪟 Windows
🐧 Linux / macOS
PowerShell — extract images and capture EXIF
# Step 1: Extract all embedded images
mutool extract lab06_exif_comments.pdf
# mutool creates files like img-0001.jpg, img-0002.jpg, img-0003.jpg
# List the extracted files:
Get-ChildItem img-*.jpg | Select-Object Name, Length

# Step 2: Run ExifTool on all images and save to a report
exiftool img-0001.jpg img-0002.jpg img-0003.jpg > lab06_exif_report.txt
notepad lab06_exif_report.txt

# For each image, find and record these fields:
# File Name        <- which image file
# Make             <- camera/scanner manufacturer
# Camera Model Name OR Model <- specific device
# Date/Time Original <- when the image was captured
# GPS Latitude     <- if present, the capture location
# GPS Longitude    <- if present, the capture location

# Quick scan for just the key fields:
exiftool -FileName -Make -Model -DateTimeOriginal -GPSLatitude -GPSLongitude img-*.jpg
Bash — extract images and capture EXIF

What to record

Write these down in your notes before moving on:

  • For each image: Make (manufacturer) and Model (device name)
  • For each image: DateTimeOriginal — when it was actually captured
  • For each image: GPS present? (yes/no)
  • Which image(s) have a Make/Model inconsistent with a Canon scanner?
  • Which image has GPS data embedded?

📝 Knowledge Check Preparation

Q1: EXIF Make='SAMSUNG', Model='SM-G991B'. Document claims all images are scanned. What is the significance?
The Samsung SM-G991B is a Galaxy S21 smartphone — not a scanner. EXIF Make and Model fields identify the physical device that captured the image. A smartphone-originated image in a document where all images are claimed to be scanner output is a significant anomaly. The device discrepancy contradicts the claimed capture workflow.
Q2: ExifTool shows GPSLatitude: 25.2048, GPSLongitude: 55.2708. Document claims London. What should you do?
25.2°N, 55.3°E is Dubai, UAE — not London, UK. Document the specific GPS values, look up the location independently (maps.google.com?q=25.2048,55.2708), note the discrepancy with the stated provenance, and seek corroborating evidence. Note: GPS data can be edited, so this finding requires corroboration but is significant evidence.
Q3: Which ExifTool command extracts GPS coordinates in decimal degree format from all JPEGs?
exiftool -csv -GPSLatitude# -GPSLongitude# img-*.jpg — the # suffix forces numeric (decimal degree) output instead of the default degrees/minutes/seconds format. The -csv flag formats the output as comma-separated values that can be pasted directly into a mapping service or spreadsheet.
Q4: Annotation has /T (D. Chen). What does /T represent and how reliable is it?
The /T field is the annotation's author or title field. It is set to whatever name is configured in the annotating user's PDF editor preferences at the time the annotation was created — typically the OS username or a user-entered name. It has no cryptographic verification and can be set to any string. Use it as an investigative lead, not as definitive proof of authorship.
Q5: When using mutool extract, where are files saved?
To the current working directory — wherever your terminal session is located when you run the command. Navigate to your intended output folder before running mutool extract, or the files will appear in whatever directory you are currently in.
