📋 Prerequisites

This course assumes working knowledge of: cryptographic hashing (MD5/SHA-256), byte offsets and hexadecimal notation, command-line tool usage, and basic concepts of file formats. No prior PDF knowledge is required. Module 01 covers everything you need.
