Module 03

Incremental Updates & Prior Versions

Every time a PDF is saved, it may leave a record of its previous state. Learn to find, count, and extract these hidden prior versions.

⏱ ~50 minutes📄 Lab file: lab03_incremental.pdf

🎯 Learning Objectives

  1. Explain how the incremental update mechanism works at the byte level
  2. Count %%EOF markers using three methods and interpret the result
  3. Extract all prior versions as standalone PDF files and verify their content
  4. Compare metadata across versions to identify application changes, backdated timestamps, and fields that appear or disappear between saves
  5. Reconstruct the full edit timeline from content changes, annotation timestamps, and object-level xref analysis
  6. Explain what incremental update analysis cannot detect and why a single %%EOF does not mean a document is unedited
